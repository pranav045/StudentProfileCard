# Student Profile Card with Expand/Collapse in Jetpack Compose

## 📖 Overview
This Android project demonstrates how to build a **student profile card** using **Jetpack Compose** with smooth expand/collapse animations. It highlights the use of `AnimatedVisibility`, `animateColorAsState`, and Material3 components to create an interactive and modern UI.

---

## ✨ Features
- 📋 Displays student details (name, year, email, phone, attendance).
- 🎭 Expand/Collapse functionality using `AnimatedVisibility`.
- 🎨 Animated button color transition with `animateColorAsState`.
- 🖼️ Material3 `Card` and `Button` components for clean UI design.
- ⚡ Responsive layout with `Column` and padding.

---

## 🛠️ Tech Stack
- **Language:** Kotlin  
- **UI Toolkit:** Jetpack Compose  
- **Design:** Material3 Components  
- **Animations:** `AnimatedVisibility`, `fadeIn`, `fadeOut`, `animateColorAsState`  

---

## 🚀 How It Works
1. The profile card shows basic student info (name, year).  
2. A button toggles between **Show Details** and **Hide Details**.  
3. On expand, additional details (email, phone, attendance) fade in.  
4. The button background color animates smoothly when toggled.  

---

## 📂 Project Structure
- `PractiseApi` → Main Activity hosting the Compose UI.  
- `DetailScreen` → Composable function rendering the student profile card.
